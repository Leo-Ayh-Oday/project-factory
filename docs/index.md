# Project Factory

**Claude Code 技能包 — 两层架构，9 个 Skill，纯 prompt 驱动。**

## 快速开始

```bash
git clone https://github.com/Leo-Ayh-Oday/project-factory.git
cp -r project-factory/skills/* ~/.claude/skills/
```

## 技能清单

### Layer 1: Project Foundation（项目底座）

| Skill | 用途 |
|-------|------|
| `/init-project` | 新项目一键生成骨架 |
| `/setup-rules` | 扫描项目 → 生成编码规则 |
| `/openwolf` | 上下文自动化管理 |

### Layer 2: Skills Pack（日常开发）

| Skill | 用途 |
|-------|------|
| `/markitdown` | 任意格式 → Markdown |
| `/screenshot-to-spec` | 截图 → 结构化需求 |
| `/learn-from-bugs` | buglog 挖掘重复错误 |
| `/estimate` | 需求改动范围评估 |
| `/obsidian` | AI 产出 → 永久笔记 |
| `/daily-digest` | 生成结构化日报 |
